### 📈 What I care about

- **Things that cannot break quietly.** Venure's database makes double booking impossible: in a test, 50 people paying for one slot at the same moment create exactly 1 booking. In SweetNest, a checkout race (10 coupon orders created 8) became 1.
- **Testing.** About 1,700 automated tests across Venure's backend, frontend and browser suites (Jest, Vitest, Playwright), run in GitHub Actions with CodeQL.
- **Measuring before changing.** Venure search went from 1,201 ms to 19 ms and its booking lists got 70 to 86% faster (k6 load tests). Lighthouse on the live site is 94 on desktop and 82 on mobile, with no layout shift.
- **Writing it down.** Each repo has a README with real numbers, plus deployment and performance notes.
